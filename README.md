# 🎮 Game Picker Galaxy 🌌

Welcome to **Game Picker Galaxy** – your one-stop interactive game chooser!  
Whether you're in the mood for something fast and thrilling ⚡ or slow and relaxing 🐢, solo 👤 or multiplayer 👥 — this app has something for everyone.

---

## 🚀 What is Game Picker Galaxy?

**Game Picker Galaxy** is a game within a game – a fun project that helps you decide *what* to play based on *how* you want to play!

Just select:
- 🎭 **Play Style**: Solo or Multiplayer  
- ⏱️ **Game Pace**: Fast or Slow  
...and voilà! The perfect mini-game appears like magic! 🧙‍♂️✨

It's not just a game selector — it actually contains **multiple playable mini-games**, all in one place!

---

## 🧩 Features

✅ Interactive and user-friendly UI  
✅ Built-in games ready to play  
✅ Solo 👤 or Multiplayer 👥 options  
✅ Fast-paced ⚡ or Chill 🐢 game filters  
✅ Random game option 🎲 for indecisive moments  
✅ Sleek design and fun animations 🎨
